# Project Title
resolveIT 

---

## Overview
Project regarding a Website for Submission of Complaints of the User where the Admin can View the Complaints and assign it to different departments for resolving the Complaints 

---

## Problem Statement
Specially Dedicated website for a User to submit their Complaints and Feedback would help them have great impression and loyalty for the company but most of the websites do not do that but this project has a solution for that

---

## Solution
Completely organized functional website that lets the Users log in to submit Complaint and which is resolved by the Admin and Staffs
